# Ori Ascendant

An idle-cultivation mobile game built in Unity, grounded in Igala/Yoruba/Igbo cosmology — you nurture your Orí (destiny-head) along orisha paths, accumulating Àṣẹ through play and idle time. **In active development.**

## What makes it different

Idle-cultivation games are usually skinned in generic xianxia fantasy. Ori Ascendant swaps that for a specifically West-African cosmological frame: the progression vocabulary, palette (indigo + Àṣẹ-gold), adire textile motifs, and correct Yoruba orthography are all part of the design contract, documented in an art bible with a native-speaker review gate before anything ships.

## Where it is

- Core idle loop playable in Unity (C#)
- Currently mid art-direction effort: replacing placeholder visuals with the "Painterly Cosmic Myth" direction through in-engine craft — gradients, shaders, particles, typography — rather than imported painted art
- Art direction validated through generated reference probes (kept/rejected against red-line checks) before anything becomes a final asset

## Project discipline

- [`CONTEXT.md`](CONTEXT.md) — ubiquitous language for the project, so "probe" vs "final asset" vs "procedural skin" never blur
- `docs/ART_BIBLE.md` — palette, cosmology vocabulary, cultural red lines
- Docs-as-code workflow: every visual decision traces to a written direction
